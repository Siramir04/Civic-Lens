# CivicLens (v0.1)
## AI-Augmented Citizenship & Strategic Intelligence

**CivicLens** is a high-fidelity intelligence platform designed to bridge the data gap in sovereign regional governance. Built with a "Material 3 Expressive" aesthetic, it provides a real-time, AI-synthesized audit of Nigeria's 36 states plus the FCT, focusing on critical development sectors through the lens of verified cognitive grounding.

---

## 🏛 Core Pillars

### 1. Spatial Observation (The "State of the Union" Map)
A high-precision interactive map of Nigeria that visualizes "Signal Intensity" across states.
- **Dynamic Shading:** States are shaded based on their **Quality Index** or **National Percentile Rank**.
- **Contextual Anchoring:** Clicking a state node initializes a deep-dive cognitive synthesis of that region.

### 2. Strategic Depth Audit (The Intelligence Stream)
A multi-layered analysis panel that evaluates state performance across four core strategic sectors:
- **🛡 Security:** Conflict intensity, police response, and regional stability.
- **🎓 Education:** Literacy rates, facility index, and enrollment volatility.
- **🌱 Agriculture:** Yield performance, market accessibility, and climate resilience.
- **🏗 Infrastructure:** Road network integrity, power distribution, and digital coverage.

### 3. AI Gap-Fill & Reasoning Chains
When hard data is stale or unavailable, CivicLens utilizes a **Synthetic Data Injection** protocol.
- **Cognitive Grounding:** The Gemini-powered engine cross-references historical baselines with real-time news signals.
- **Reasoning Chains:** Users can peer into the "brain" of the AI to see the logic, drift variance, and grounding findings behind estimated scores.

### 4. Source Audit & Protocol V-7
A decentralized contributor layer allowing users to submit and validate information sources.
- **Integrity Coefficient:** Sources are scored on independence, history, and accuracy.
- **Strategic Validation:** AI-driven grounding scans evaluate the bias and reliability of submitted endpoints.

## 🧪 Technical Stack

- **Framework:** React 18 + Vite
- **Intelligence Engine:** Gemini 1.5 Flash (via `@google/genai`)
- **Styling:** Tailwind CSS (Modernist/Industrial aesthetic)
- **Motion:** Framer Motion (Route transitions, staggered entrances, layout animations)
- **Icons:** Lucide React
- **Data Architecture:** Service-oriented architecture for AI synthesis and news grounding.

---

## 🎨 Design Philosophy: Material 3 Expressive
CivicLens departs from generic UI in favor of a "Technical Editorial" look:
- **Typography:** Outfit (Display) for bold, high-contrast headings; Inter for UI; JetBrains Mono for data points.
- **Color Space:** Deep carbon backgrounds (`#0A0A0B`) with high-chroma emerald and rose accents for signal indicators.
- **Physicality:** Large border radii (4xl), heavy backdrop blurs, and "glassmorphism" depth layers to simulate a high-end surveillance console.

## 🚀 Environment Setup

1. **Clone & Install**
   ```bash
   npm install
   ```

2. **Configure Environment**
   Create a `.env` file or set the following variable:
   ```env
   GEMINI_API_KEY=your_google_ai_studio_api_key
   ```

3. **Run Development Mode**
   ```bash
   npm run dev
   ```
